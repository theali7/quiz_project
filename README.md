# quiz_project

# Турнир-викторина

Консольный учебный проект на Python. Пользователь выбирает язык программирования и уровень сложности, отвечает на вопросы и получает результат.

## Возможности

- Выбор темы: Python, Java или C++.
- Три уровня сложности: лёгкий, средний и сложный.
- По 5 вопросов для каждого языка и уровня — всего 45 вопросов.
- Четыре варианта ответа на каждый вопрос.
- Подсчёт правильных и неправильных ответов.
- Вывод номеров вопросов, на которые пользователь ответил верно и неверно.

## Запуск

Для запуска требуется Python 3. Дополнительные библиотеки не нужны.

Склонируйте репозиторий:

```bash
git clone https://github.com/theali7/quiz_project.git
cd quiz_project
```

Запустите программу:

```bash
python3 practice.py
```

## Как играть

1. Выберите «Начать игру».
2. Введите своё имя.
3. Выберите язык программирования.
4. Выберите уровень сложности.
5. Отвечайте на вопросы, вводя номер варианта от 1 до 4.
6. Посмотрите результат после завершения игры.

## Хранение данных

Вопросы находятся в списке словарей внутри программы. Каждый вопрос содержит:

- `id` — номер внутри темы и уровня;
- `topic` — язык программирования;
- `difficulty` — сложность;
- `question` — текст вопроса;
- `options` — варианты ответа;
- `answer` — номер правильного варианта.

Данные, добавленные во время работы, пока не сохраняются после закрытия программы.

## В разработке

- Просмотр таблицы результатов.
- Добавление новых вопросов и тем через меню.
- Проверка ввода ответа.
- Выход через главное меню.
- Подсчёт баллов с учётом сложности.
- Разбор ошибок с показом правильных ответов.

## Цель проекта

Закрепить основы Python: условия, циклы, функции, строки, списки, словари и множества.
